# External source favicons

These files are local snapshots of provider favicons used only to identify the
linked source. They are not TerraResources brand assets. The parent
`favicon-manifest.json` records the upstream URL, source page, dimensions, and
checksum for each file.

Provider names and marks remain the property of their respective organizations.
If a provider changes or withdraws permission for a mark, replace or remove the
local copy rather than continuing to redistribute it.
