# TerraResources brand mark

The active mark is `wayfinder-junction.svg`: a clay route and lime branch meet at
one waypoint. It represents Geography, fieldwork, and the site's main promise of
turning scattered inputs into a useful path forward.

The mark avoids the generic globe-and-location-pin language of the original logo.
It is exported to the following runtime assets:

- `public/brand-mark.svg` — interface and social mark
- `public/favicon.svg` / `public/favicon.png` — browser icon
- `public/icon-192.png`, `public/icon-512.png` — installable icons
- `public/maskable-icon-512.png` — maskable installable icon

The palette remains intentionally small: deep forest for structure, lime for active
signals, and clay for the waypoint/emphasis role.

`favicon-manifest.json` records the upstream favicon URL, local copy, dimensions,
and checksum for each external source. Those marks remain the property of their
respective organizations; the manifest is kept so they can be audited or
replaced without guessing.
